= glow-adoc

Read AsciiDoc in a terminal. Includes a pager, syntax highlighting, tables, collapsible blocks,
terminal colours and Kitty graphics. Uses AsciidoctorJ; requires Java 27+.

== Install

Build from source with Java 27:

[source,sh]
----
./gradlew checkAll :cli-jvm:install
export PATH="$HOME/.local/bin:$PATH"
----

Installation replaces `~/.local/bin/glow-adoc`. The launcher selects an installed Java through
mise, SDKMAN!, asdf-vm, jenv, jabba, JAVA_HOME, then PATH. It never downloads a JDK.

A link:packaging/homebrew/glow-adoc.rb[Homebrew formula template] is supplied for future releases.
Fill in its repository, version and checksum before use. Native Image remains experimental.

== Usage

[source,sh]
----
glow-adoc document.adoc
glow-adoc --width=100 --center=true document.adoc
glow-adoc --no-pager --color=never document.adoc
cat document.adoc | glow-adoc -
glow-adoc -a image-assets="$PWD/static/assets" content/posts/post.adoc
glow-adoc --help
----

A terminal opens the pager. Redirected output is text, 80 columns by default.
`--no-pager` selects direct output; `--width` changes the content width.
The regular jar also supports `java -jar cli-jvm/build/libs/glow-adoc-0.1.0-SNAPSHOT.jar document.adoc`.

== Pager

Use arrows or `j/k` to scroll, Space/Page Down and `b`/Page Up to page, `g/G` for start/end.
Left/right scroll wide code and tables. Press `q` or Ctrl-C to quit.

`/` highlights literal matches while typing. The nearest match is selected, with ties favouring
the match above. Enter keeps it, Escape restores the reading position, and `n/N` cycle occurrences.

Tab/Shift-Tab focus collapsible headers; Enter or a click toggles them.
The mouse wheel scrolls three lines. Press `m` to toggle mouse capture.
Use Shift-drag for native selection in terminals that support it, or `--mouse=false`.

== Project settings

Place `.glow-adoc.local.toml` or `.glow-adoc.toml` at the project root:

[source,toml]
----
image-roots = ["static"]

[attributes]
image-assets = "assets"
----

Discovery starts beside the document and searches parents, trying the local file first at each level.
The first file overrides user settings; CLI values win. Stdin uses the working directory.
See link:docs/REFERENCE.adoc[the reference] for paths, precedence and options.

== Images and diagrams

PNG/JPEG images use Kitty graphics in supported terminals. Image data travels through the terminal
connection, including SSH; the terminal does not need access to image files.
An absolute directory supplied through `-a` also allows image reads from that directory.
Other external image directories need `--image-root` or `image-roots`.

PlantUML's MIT distribution is embedded; ditaa is unavailable.
Mermaid uses an optional, separately installed Merman:

[source,sh]
----
brew install merman-cli
# Alternative:
cargo binstall merman-cli
----

Platform archives are available from https://github.com/Latias94/merman/releases[Merman releases].
Verify checksums. Integration tests use Merman 0.8.0; Gradle never installs it.
Missing renderers retain diagram source.

== Startup and troubleshooting

Text appears before syntax highlighting and diagram rendering complete. Visible diagrams render in
the background. Images upload once and are reused while scrolling.
Unchanged files skip JRuby through a private conversion cache. Completed highlights are also reused
across launches. `--no-cache` bypasses both disk caches.
Optional local AOT training can reduce startup time:

[source,sh]
----
glow-adoc --train-aot fixtures/showcase.adoc
glow-adoc --timings document.adoc
----

Training is explicit. Matching caches load automatically through the executable launcher.
See link:docs/PERFORMANCE.adoc[performance] and link:docs/TROUBLESHOOTING.adoc[troubleshooting].
