= glow-adoc

glow-adoc makes AsciiDoc comfortable to read in your terminal, with a searchable pager,
highlighted code, aligned tables, colourful admonitions and collapsible sections.

* Search as you type, follow clickable links and navigate with the keyboard or mouse.
* Read with automatic light/dark themes and text that wraps at 120 columns by default.
* View local images through Kitty graphics, including over SSH, and render PlantUML diagrams.
* Open files or stdin, or write formatted text directly to stdout.

Built with https://github.com/asciidoctor/asciidoctorj[AsciidoctorJ] for parsing,
https://github.com/tamboui/tamboui[TamboUI] for the pager,
https://github.com/roastedroot/lumis4j[Lumis4J] for highlighting and
https://github.com/plantuml/plantuml[PlantUML] for diagrams.
Mermaid support uses optional https://github.com/Latias94/merman[Merman]: `brew install merman-cli`.

== Install

The pager runs on macOS and Linux with Java 27+. A Nerd Font enables the default icons.

=== Homebrew

The formula will be published in https://github.com/bric3/homebrew-bric3[bric3/bric3]:

[source,sh]
----
brew install bric3/bric3/glow-adoc
----

=== From source

From a checkout, with Java 27 installed:

[source,sh]
----
./gradlew :cli-jvm:install
export PATH="$HOME/.local/bin:$PATH"
----

Installation pretrains a local AOT cache and writes `~/.local/bin/glow-adoc`.
Use `:cli-jvm:installWithoutAot` to skip training.

== Read

[source,sh]
----
glow-adoc document.adoc
glow-adoc --width=100 --center=true document.adoc
glow-adoc --no-pager --color=never document.adoc
cat document.adoc | glow-adoc -
----

Press `/` to search, `n/N` to cycle matches, Tab/Enter to toggle sections and `q` to quit.
Press `m` to switch between mouse controls and terminal text selection.

== Configure

Use CLI options or TOML settings. CLI values override project settings, which override user settings.
User settings live in `~/.config/glow-adoc/config.toml`, or under `$XDG_CONFIG_HOME`.
Project lookup starts beside the document and searches parents, checking `.glow-adoc.local.toml`
before `.glow-adoc.toml` at each level. It stops at the first match; stdin uses the working directory.

[cols="2,2,3",options="header"]
|===
|CLI example |TOML equivalent |Effect
|`--no-pager` |`pager = false` |Write directly to stdout.
|`--width=100`, `--center=true` |`width = 100`, `center = true` |Set the reading width and centre the content.
|`--theme=dark`, `--color=always` |`theme = "dark"`, `color = "always"` |Override automatic appearance detection.
|`--icons=unicode`, `--callouts=circle` |`icons = "unicode"`, `callouts = "circle"` |Choose icons and numbered code markers.
|`--images=auto`, `--image-dim=false` |`images = "auto"`, `image-dim = false` |Display supported images at full brightness.
|`--mouse=false`, `--progress=never` |`mouse = false`, `progress = "never"` |Control mouse capture and the terminal progress indicator.
|`--page-background=true` |`page-background = true` |Fill the page background.
|`--table-stripes=false` |`table-stripes = false` |Disable alternating table backgrounds.
|`--table-frame=all`, `--table-grid=rows` |`table-frame = "all"`, `table-grid = "rows"` |Choose outer and internal table borders.
|`--table-section-borders=heavy` |`table-section-borders = "heavy"` |Emphasise header and footer separators.
|`--shortcodes=show` |`shortcodes = "show"` |Show Hugo shortcode tags, which are hidden by default.
|`-a image-assets=assets` |`[attributes]` with `image-assets = "assets"` |Supply attributes referenced by the document.
|`--image-root=static` |`image-roots = ["static"]` |Allow images from an additional directory.
|`--config=settings.toml` |CLI only. |Read an explicit settings file.
|`--no-cache`, `--timings`, `--train-aot` |CLI only. |Bypass disk caches, inspect startup timings or retrain AOT.
|===

Run `glow-adoc --help` or read the link:docs/REFERENCE.adoc[CLI reference] and
link:docs/config.toml[complete TOML example] for all values, defaults and path rules.
