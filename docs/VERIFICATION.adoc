= Verification

== Automated checks

[source,sh]
----
./gradlew checkAll
GLOW_TEST_MERMAN=/path/to/merman-cli ./gradlew :diagrams:test
----

The second command enables an optional integration with a separately reviewed executable.
Without it, that test is skipped. Ordinary builds never install Merman.

Coverage includes conversion, inline styles, callouts, tables/spans, wrapping/graphemes, HTML filtering,
shortcodes, includes, configuration precedence, CLI attributes, allowed image roots and symlink escapes.
Highlighter tests cover source preservation, progressive output, cache reuse and cancellation.

PTY checks cover keys/mouse, search, folding, themes, images and terminal restoration.
Image tests assert unchanged frames emit no commands, scrolling reuses uploaded pixels,
crops use source coordinates, off-screen data can be evicted and exit releases owned images.
Launcher checks cover manager priority, installed-version selection, spaces, arguments,
exit codes, opt-in AOT training, cache invalidation and corrupt-cache fallback with clean stdout.

== Performance

See link:PERFORMANCE.adoc[the measurement procedure and local results].
Measurements use fresh JVMs. Repeated launches normally have warm filesystem caches;
these are not equivalent to dropping the operating system's disk cache.

== Platform limits

Local automated checks run on macOS ARM64. CI is configured for Linux/macOS.
PTY transmission does not verify visual appearance, fonts or real-terminal rendering.
Manually check iTerm2/Ghostty, SSH, resize, scrolling, theme changes and cancellation before release.

Native Image compilation previously succeeded with GraalVM 25, but JRuby startup failed on missing
reflection metadata for `org.jruby.util.log.StandardErrorLogger`. Native runtime support remains experimental;
compilation alone is not a compatibility check. This performance change does not repair that blocker.

The Homebrew formula is a release template until repository, version and checksums are supplied.
