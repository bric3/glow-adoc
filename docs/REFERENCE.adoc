= CLI reference

== Invocation

`glow-adoc [OPTIONS] FILE|-` reads one file or stdin. The pager requires a macOS/Linux terminal.
Direct output also supports Windows. Exit status is zero on success and non-zero on failure.

[cols="2,1,4",options="header"]
|===
|Option |Default |Meaning
|`--no-pager` |off |Write directly to stdout.
|`--no-cache` |off |Bypass reading and writing conversion and syntax highlighting disk caches.
|`--width N` |120 |Content width, 1-1000 cells, limited by terminal width.
|`--center true/false` |false |Centre width-limited content.
|`--color auto/always/never` |auto |Auto respects NO_COLOR and TERM=dumb.
|`--theme auto/light/dark` |auto |Follow terminal appearance, or fix the theme.
|`--images auto/never` |auto |Use graphics when the terminal answers the capability query.
|`--icons nerd/unicode/ascii` |nerd |Select glyphs. Font support is not detected.
|`--mouse true/false` |true |Capture clicks and wheel events.
|`--progress auto/always/never` |auto |Show OSC 9;4 reading position on recognised terminals.
|`--image-dim true/false` |true |Dim dark-mode images until hovered in mouse mode.
|`--callouts pill/circle/ascii` |pill |Select numbered callout markers.
|`--page-background true/false` |false |Fill ordinary text and margins.
|`--table-stripes true/false` |true |Alternate cell backgrounds.
|`--table-frame auto/all/sides/ends/none` |auto |Select outer table borders.
|`--table-grid auto/all/rows/cols/none` |auto |Select internal table borders.
|`--table-section-borders thin/heavy` |thin |Style enabled header/footer rules.
|`--shortcodes hide/show` |hide |Show or hide Hugo shortcode tags.
|`-a, --attribute NAME=VALUE` |none |Repeatable external attributes; last value wins.
|`--image-root PATH` |none |Repeatable image directory, relative to the working directory.
|`--config FILE` |discovery |Read this file over application defaults.
|`--timings` |off |Write cumulative startup stages to stderr.
|`--train-aot [FILE]` |manual |Train the bundled corpus, or FILE; launcher only, first option.
|`--version`, `--help` | |Print version or usage.
|===

== Configuration

User settings: `$XDG_CONFIG_HOME/glow-adoc/config.toml`, falling back to
`~/.config/glow-adoc/config.toml`. Windows uses `%APPDATA%/glow-adoc/config.toml`,
falling back to `~/AppData/Roaming/glow-adoc/config.toml`. See link:config.toml[the complete example].

Project lookup starts beside the document, or in the working directory for stdin.
Each directory is checked for `.glow-adoc.local.toml`, then `.glow-adoc.toml`.
Lookup stops at the first file found. Ignore the local filename in your project's Git configuration.

Precedence: CLI, nearest project file, user configuration, defaults.
Attribute tables merge by name; image-root arrays replace inherited arrays.
Explicit `--config` bypasses discovery. Malformed files, invalid values and unknown keys are errors.

The link:config.toml[example] lists all configuration keys. `pager = false` disables paging;
`width = 0` follows terminal width. Help, version, config selection, cache bypass, timings and AOT training are CLI-only.
`attributes` is a table of strings; `image-roots` is an array of paths.
`merman` selects an executable in user or explicit configuration; discovered project files cannot select one.

== Attributes and resources

Values preserve commas and equals signs. A name without `=VALUE` defines an empty attribute.
Use the name referenced by the document: `image-assets` and `image-asset` are distinct.

Includes stay inside the document directory. Include selectors (`tag`, `tags`, `lines`) are unsupported.
Images may use that directory, declared roots, or absolute directory values explicitly supplied as CLI attributes.
Symbolic links are checked against the allowed directories.

Configuration roots are relative to the configuration file. Discovered roots stay inside its directory tree.
User configuration, explicit files and CLI roots may allow other directories.
The standard `imagesdir` attribute prefixes relative image targets.
The pager fetches HTTPS badges from `img.shields.io` and GitHub Actions after the first text frame.
Requests have a three-second deadline, a 256 KiB source limit and no redirects. `--images=never`
disables these requests. Other remote images and HTML resources retain text fallbacks.
Local SVGs have the same source limit and a two-megapixel raster limit. SVG external resources are disabled.
SVG raster density follows the reported cell height against a 16 px reference text line, keeping
badges readable on HiDPI displays. New cell-size replies select a new density, capped at 4096 px per axis and
two megapixels. A missing cell-size reply uses the 8 x 16 fallback.
Adjacent inline images share a row with a one-cell gap and wrap at the reading width. Block images
remain separate. Image proportions are preserved, with at most 1000 rows per image; extreme aspect
ratios that cannot fit one column retain text fallbacks.

== Rendering

Text wraps to the content width; the final terminal column is reserved. Code scrolls horizontally.
Detected YAML front matter preserves indentation and line boundaries without a box.
A horizontal rule separates it from the document body.
Table cells wrap; structures wider than the viewport remain scrollable. Auto borders follow AsciiDoc frame/grid attributes.
Source titles use italic text inside the top border. Callout pills use regular numbers on a contrasting
background, with rounded ends in Nerd mode. Circle mode uses ❶ through ❿, then parenthesised numbers.
ASCII glyphs and unstyled output use parenthesised numbers throughout.

Soft source line breaks reflow with surrounding prose. Explicit breaks, `hardbreaks`, verse and code retain
their line boundaries. Superscript references use bracketed labels such as `[1]`, preserving their links.
Admonitions use blue for NOTE, green for TIP, purple for IMPORTANT, red for WARNING and amber for CAUTION.
Nerd mode uses `nf-fa-info` for NOTE, `nf-oct-light_bulb` for TIP,
`nf-oct-report` for IMPORTANT, `nf-oct-alert` for WARNING and `nf-md-fire` for CAUTION.
Unicode and ASCII alternatives remain available. Compare alternatives with `./tools/admonition-demo.sh`.

Hugo `{{< ... >}}` and `{{% ... %}}` tags are hidden while their contents remain.
Generic `{{ ... }}`, code/literal examples and escaped tags are preserved. Templates are not executed.

HTML passthrough supports text markup, links, lists, tables, quotes, code and details/summary.
Scripts, styles and executable elements are discarded. Arbitrary CSS is unsupported; line-through is recognised.

Direct output expands disclosures and retains image descriptions. The pager displays block images and standalone
`image:` macros graphically when supported. Images mixed into running text retain placeholders.
In dark mouse mode, images use 65% opacity until hovered. Light mode, selection mode (`m`) and
`--image-dim=false` show original images. Hover requires mouse motion reporting. Image variants are
cached; scrolling reuses uploaded pixels. Theme changes update both text and images.

External links are coloured and receive a Nerd Font suffix: `nf-cod-link_external`,
`nf-cod-issues` for GitHub/GitLab issues, or `nf-cod-git_pull_request` for pull/merge requests.
GitLab `/-/` paths also work on self-hosted instances. Suffixes remain part of the clickable link.
Unicode and ASCII modes retain the label without a suffix.

Hover highlights a link. A left-button press and release on it opens the local system browser;
dragging cancels activation. The pager calls `open` on macOS or `xdg-open` on Linux without a shell,
with a five-second timeout. Only HTTP, HTTPS and mailto targets are opened.

OSC 8 links also remain available for terminal-managed activation and with `--color=never` in the pager.
Over SSH, the pager leaves browser activation to the client terminal. In Ghostty use Shift+Cmd-click
on macOS or Shift+Ctrl-click on Linux. In iTerm2 enable Cmd-click in Pointer preferences and use
Option+Cmd-click if capture intercepts it. Press `m` to disable capture and use the terminal's usual gesture.

OSC progress follows the scroll position, reaches 100% when the document fits or its end is visible,
and clears on exit. Automatic mode recognises Ghostty, iTerm2, WezTerm, Windows Terminal and Konsole.
It disables progress inside tmux/screen; `always` forces emission. Direct output never emits progress.

== Environment

`JAVA_OPTS` supplies JVM options to the executable launcher. Its default Unsafe policy is
`-Dsun.misc.unsafe.memory.access=allow`, the OpenJDK property behind
`--sun-misc-unsafe-memory-access=allow`. The property lets older Java versions reach the bootstrap
guard. JAVA_OPTS can override it with the property or the standard flag. Direct Java invocation retains JVM defaults.
`XDG_CACHE_HOME` selects the conversion, highlighting and AOT cache root, falling back to `~/.cache`.
Conversion files use the same root under `glow-adoc/conversions`; Windows uses
`%LOCALAPPDATA%/glow-adoc/conversions`, falling back to `~/AppData/Local/glow-adoc/conversions`.
The CLI defaults `jruby.native.enabled` to `false`; override it with `-Djruby.native.enabled=true`.
See link:PERFORMANCE.adoc[performance] and link:TROUBLESHOOTING.adoc[troubleshooting].
